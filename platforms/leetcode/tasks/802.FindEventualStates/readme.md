## Суть задачи

У нас есть ориентированный граф, представленный в виде списка смежности `graph`. Вершина считается "безопасной" (safe), если:

Любой путь, начинающийся из этой вершины, либо приводит в конечную вершину, либо зацикливается на безопасных вершинах.

Необходимо вернуть список всех безопасных вершин в возрастающем порядке.

--- 

## Как подойти к задаче

Эта задача сводится к определению "терминальных" состояний и тех, которые не могут привести к "опасным" состояниям. Для этого мы можем использовать обход графа и понятие топологической сортировки.

### Интуиция решения

1. Если из вершины нет исходящих рёбер (она терминальная), то она безопасна.
2. Если из вершины есть рёбра, но все вершины, в которые они ведут, безопасны, то и она безопасна.
3. Задачу можно свести к поиску "топологически безопасных" вершин, т.е. тех, которые не участвуют в циклах.

---

## Алгоритм решения

Мы используем обратный граф и метод топологической сортировки:

1. Построим обратный граф (reversed graph), где рёбра будут указывать в обратную сторону.
2. Подсчитаем входящие степени для каждой вершины.
3. Используем очередь для поиска вершин с входящей степенью 0 (это терминальные вершины).
4. Итеративно удаляем вершины из графа, обновляя входящие степени, пока не обработаем все безопасные вершины.
5. Вершины, которые мы удалили в процессе, являются безопасными.
