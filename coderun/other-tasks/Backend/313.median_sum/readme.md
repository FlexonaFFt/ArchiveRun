### Задача:
Нужно найти сумму всех медианных значений для каждого подмножества массива, начиная с первого элемента и заканчивая текущим элементом.

### Пример 1:
Входные данные:
```
10
5 10 8 1 7 3 9 6 2 4
```
Нужно найти медианы для подмассивов:
- [5]
- [5, 10]
- [5, 10, 8]
- ...
- [5, 10, 8, 1, 7, 3, 9, 6, 2, 4]

### Что такое медиана?
Медиана — это такое число в упорядоченном множестве, что половина элементов меньше этого числа, а другая половина больше. Если количество элементов нечётное, медиана — это средний элемент. Если чётное — это среднее значение двух средних элементов.

### Алгоритм решения:
1. Читаем входные данные.
2. Для каждого подмассива находим медиану.
3. Суммируем все найденные медианы.

### Реализация на Python:

```python
import heapq

def find_medians_sum(n, arr):
    lower_half = []  # Максимальная куча для элементов меньшей половины
    upper_half = []  # Минимальная куча для элементов большей половины
    medians_sum = 0

    for i in range(n):
        num = arr[i]

        # Вставляем элемент в соответствующую кучу
        if len(lower_half) == 0 or num <= -lower_half[0]:
            heapq.heappush(lower_half, -num)
        else:
            heapq.heappush(upper_half, num)

        # Балансировка куч
        if len(lower_half) > len(upper_half) + 1:
            heapq.heappush(upper_half, -heapq.heappop(lower_half))
        elif len(upper_half) > len(lower_half):
            heapq.heappush(lower_half, -heapq.heappop(upper_half))

        # Определяем текущую медиану
        if len(lower_half) >= len(upper_half):
            medians_sum += -lower_half[0]
        else:
            medians_sum += upper_half[0]

    return medians_sum

# Пример использования
n = 10
arr = [5, 10, 8, 1, 7, 3, 9, 6, 2, 4]
result = find_medians_sum(n, arr)
print(result)  # Вывод: 59
```

### Объяснение работы кода:
1. Используем две кучи:
   - `lower_half` для меньшей половины чисел, реализована как максимальная куча.
   - `upper_half` для большей половины чисел, реализована как минимальная куча.
2. Добавляем числа поочередно в одну из куч.
3. Балансируем кучи так, чтобы разница в размере куч не превышала 1.
4. На каждом шаге вычисляем медиану и добавляем её к сумме.

Этот подход позволяет эффективно находить медиану для каждой последовательности чисел.

### Пример выполнения:
Для массива `[5, 10, 8, 1, 7, 3, 9, 6, 2, 4]` медианы на каждом шаге:
- 5, 5, 8, 5, 7, 5, 7, 6, 6, 5

Их сумма будет равна 59, что и является ответом.
