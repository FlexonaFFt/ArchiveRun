Для решения задачи, давайте сначала разберемся с тем, что нам дано. У нас есть:

1. Число $$ N $$ — общее количество карт.
2. Три суммы:
   - Сумма номеров карт, которые остались у Васи.
   - Сумма квадратов номеров карт.
   - Сумма кубов номеров карт.

Нам нужно найти три отсутствующие карты $$ X, Y, Z $$.

## Алгоритм решения

1. **Вычислим полные суммы**:
   - Полная сумма всех карт от 1 до $$ N $$ (сумма арифметической прогрессии): 
     $$
     S = \frac{N \times (N + 1)}{2}
     $$
   - Полная сумма квадратов:
     $$
     S2 = \frac{N \times (N + 1) \times (2N + 1)}{6}
     $$
   - Полная сумма кубов:
     $$
     S3 = \left( \frac{N \times (N + 1)}{2} \right)^2
     $$

2. **Вычислим суммы отсутствующих карт**:
   - Сумма отсутствующих карт:
     $$
     A = S - \text{сумма оставшихся карт}
     $$
   - Сумма квадратов отсутствующих карт:
     $$
     A2 = S2 - \text{сумма квадратов оставшихся карт}
     $$
   - Сумма кубов отсутствующих карт:
     $$
     A3 = S3 - \text{сумма кубов оставшихся карт}
     $$

3. **Решим систему уравнений**:
   - Мы можем использовать метод перебора для поиска трех чисел $$ X, Y, Z $$ из диапазона от 1 до $$ N $$, которые удовлетворяют условиям:
     $$
     X + Y + Z = A
     $$
     $$
     X^2 + Y^2 + Z^2 = A2
     $$
     $$
     X^3 + Y^3 + Z^3 = A3
     $$

Теперь давайте реализуем этот алгоритм на Python.

## Реализация на Python

```python
def find_missing_cards(N, sums):
    total_sum = N * (N + 1) // 2
    total_sum_squares = N * (N + 1) * (2 * N + 1) // 6
    total_sum_cubes = (total_sum ** 2)

    sum_cards, sum_squares, sum_cubes = sums

    missing_sum = total_sum - sum_cards
    missing_sum_squares = total_sum_squares - sum_squares
    missing_sum_cubes = total_sum_cubes - sum_cubes

    # Перебираем все возможные комбинации X, Y, Z
    for x in range(1, N + 1):
        for y in range(x + 1, N + 1):
            z = missing_sum - x - y
            if z > y and z <= N:  # z должно быть больше y и в пределах [1, N]
                if (x ** 2 + y ** 2 + z ** 2 == missing_sum_squares and
                        x ** 3 + y ** 3 + z ** 3 == missing_sum_cubes):
                    return x, y, z

# Пример использования
N = int(input())
sums = list(map(int, input().split()))
missing_cards = find_missing_cards(N, sums)
print(*missing_cards)
```

## Как это работает

1. Мы вычисляем полные суммы для карт от 1 до $$ N $$.
2. Затем находим суммы отсутствующих карт.
3. Перебираем все возможные комбинации $$ X, Y, Z $$ и проверяем, удовлетворяют ли они условиям.

Этот код должен эффективно находить отсутствующие карты в заданных пределах.
