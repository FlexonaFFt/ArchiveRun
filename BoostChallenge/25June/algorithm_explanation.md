# Подробное объяснение алгоритма

## 🎯 Ключевая идея

В шахматной доске размером k×k клетки чередуются по цветам. Важно понимать:

### Четный размер (k четное)
- Количество белых клеток = k²/2
- Количество черных клеток = k²/2
- **Равное** количество клеток каждого цвета

### Нечетный размер (k нечетное)
- Одного цвета: (k²+1)/2 клеток
- Другого цвета: (k²-1)/2 клеток
- **Разница в 1** клетку между цветами

## 🔍 Алгоритм: Бинарный поиск

### Почему бинарный поиск?
- Если можем построить доску размером k, то можем построить любую доску меньшего размера
- Если не можем построить доску размером k, то не можем построить доску большего размера
- **Монотонность** → идеально для бинарного поиска

### Границы поиска
- `left = 0` (минимум)
- `right = √(n+m) + 1` (максимум, если все плитки одного цвета)

### Проверка возможности построения

```python
def can_build_board(k, n, m):
    total = k * k
    
    if k % 2 == 0:
        # Четный: нужно ровно k²/2 каждого цвета
        need_each = total // 2
        return n >= need_each and m >= need_each
    else:
        # Нечетный: нужно (k²-1)/2 и (k²+1)/2
        need_min = total // 2
        need_max = total // 2 + 1
        
        # Проверяем оба варианта распределения
        variant1 = (n >= need_max and m >= need_min)  # белых больше
        variant2 = (n >= need_min and m >= need_max)  # черных больше
        
        return variant1 or variant2
```

## 📊 Пример пошагового выполнения

### Пример 1: n=9, m=8

1. **Границы**: [0, 5] (так как √17 ≈ 4.1)

2. **Итерация 1**: mid = 3
   - 3×3 = 9 клеток
   - Нечетный размер: нужно 5 и 4
   - У нас 9 и 8 → можем ✅
   - left = 3

3. **Итерация 2**: mid = 4
   - 4×4 = 16 клеток
   - Четный размер: нужно 8 и 8
   - У нас 9 и 8 → можем ✅
   - left = 4

4. **Итерация 3**: mid = 5
   - 5×5 = 25 клеток
   - Нечетный размер: нужно 13 и 12
   - У нас 9 и 8 → не можем ❌
   - right = 4

5. **Результат**: 4

### Пример 2: n=12, m=15

1. **Границы**: [0, 6] (так как √27 ≈ 5.2)

2. **Итерация 1**: mid = 3 → можем → left = 3

3. **Итерация 2**: mid = 5
   - 5×5 = 25 клеток
   - Нечетный размер: нужно 13 и 12
   - Вариант 1: 13 белых, 12 черных (у нас 12 белых) ❌
   - Вариант 2: 12 белых, 13 черных (у нас 12 и 15) ✅
   - left = 5

4. **Итерация 3**: mid = 6
   - 6×6 = 36 клеток
   - Четный размер: нужно 18 и 18
   - У нас 12 и 15 → не можем ❌
   - right = 5

5. **Результат**: 5

## ⚡ Сложность алгоритма

- **Временная**: O(log(√(n+m))) = O(log(n+m))
- **Пространственная**: O(1)

## 🔑 Ключевые моменты

1. **Формула для нечетного размера**: всегда есть два варианта распределения цветов
2. **Бинарный поиск по ответу**: эффективно находит максимум
3. **Границы поиска**: √(n+m) как верхняя граница
4. **Проверка**: простая арифметика для каждого размера
