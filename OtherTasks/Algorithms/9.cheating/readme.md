## Решение задачи о разделении студентов на две группы

Для решения этой задачи можно использовать алгоритм поиска двудольного паросочетания в графе. Идея состоит в том, чтобы построить граф, в котором вершины соответствуют студентам, а ребра - парам студентов, обменивающихся записками. Затем проверяем, существует ли двудольное паросочетание в этом графе.

Если такое паросочетание существует, то мы можем разделить студентов на две группы так, что любой обмен записками происходит между студентами из разных групп. В противном случае, разделить студентов на две группы невозможно.

Реализуем алгоритм на Python:

```python
from collections import defaultdict

def can_divide_students(n, pairs):
    graph = defaultdict(list)
    for u, v in pairs:
        graph[u].append(v)
        graph[v].append(u)
    
    def dfs(node, color):
        visited[node] = color
        for neighbor in graph[node]:
            if neighbor not in visited:
                if not dfs(neighbor, 1 - color):
                    return False
            elif visited[neighbor] == visited[node]:
                return False
        return True
    
    visited = {}
    for node in range(1, n+1):
        if node not in visited:
            if not dfs(node, 0):
                return "NO"
    return "YES"

# Пример использования
n, m = map(int, input().split())
pairs = []
for _ in range(m):
    u, v = map(int, input().split())
    pairs.append((u, v))

print(can_divide_students(n, pairs))
```

Алгоритм работает следующим образом:

1. Строим граф, используя defaultdict для эффективного хранения списков смежности.
2. Определяем функцию `dfs`, которая выполняет поиск в глубину, раскрашивая вершины в два цвета (0 и 1). Если при обходе находится ребро, соединяющее вершины одного цвета, то возвращаем `False`, так как разделить студентов на две группы невозможно.
3. Запускаем `dfs` для каждой непомеченной вершины. Если хотя бы для одной вершины `dfs` вернет `False`, то возвращаем "NO".
4. Если все вершины успешно раскрашены, то возвращаем "YES".

Временная сложность алгоритма O(|V| + |E|), где |V| - количество студентов, а |E| - количество пар студентов, обменивающихся записками. Пространственная сложность O(|V| + |E|) для хранения графа.

Таким образом, если существует двудольное паросочетание в графе, то профессор Флойд может разделить студентов на две группы, чтобы любой обмен записками происходил между студентами из разных групп. В противном случае, такое разделение невозможно[2][3].
