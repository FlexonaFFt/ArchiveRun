Для решения задачи вычисления дня недели для заданной даты мы можем воспользоваться встроенным модулем `datetime` в Python. Этот модуль содержит функции для работы с датами и временем, и позволяет легко определить день недели для любой заданной даты.

### Пошаговый алгоритм:
1. **Прочитать входные данные**.
2. **Использовать `datetime` для вычисления дня недели**.
3. **Вывести название дня недели в требуемом формате**.

### Основные моменты:
- В Python метод `datetime.date(year, month, day).weekday()` возвращает день недели, где понедельник — 0, а воскресенье — 6.
- Чтобы преобразовать этот результат в нужный формат, потребуется список дней недели на английском языке.

### Пример кода:

```python
import sys
import datetime

# Список дней недели
weekdays = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]

# Преобразование названия месяца в число
month_to_number = {
    "January": 1,
    "February": 2,
    "March": 3,
    "April": 4,
    "May": 5,
    "June": 6,
    "July": 7,
    "August": 8,
    "September": 9,
    "October": 10,
    "November": 11,
    "December": 12
}

# Чтение всех входных данных
input_data = sys.stdin.read().strip().splitlines()

# Для каждой строки с датой вычисляем день недели
for line in input_data:
    day, month, year = line.split()
    day = int(day)
    year = int(year)
    month = month_to_number[month]

    # Определение дня недели
    date = datetime.date(year, month, day)
    day_of_week = weekdays[date.weekday()]

    # Выводим результат с заглавной буквы
    print(day_of_week)
```

### Объяснение:
- **Входные данные** читаются из `sys.stdin.read()`, что позволяет обрабатывать большое количество строк эффективно.
- **`datetime.date(year, month, day)`** создает объект даты.
- **`date.weekday()`** возвращает индекс дня недели, который затем используется для доступа к соответствующему названию дня недели в списке `weekdays`.
- Название дня недели выводится с заглавной буквы, так как в списке `weekdays` они уже указаны в нужном формате.

### Пример работы:
Для ввода:
```
1 January 2015
31 December 2015
```
Вывод будет:
```
Thursday
Thursday
```

Этот код эффективен и справляется с задачей в пределах установленных ограничений по времени и памяти.
